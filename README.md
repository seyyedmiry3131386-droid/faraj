# راوی

کد قابل اجرا و تغییرات جدید در پوشهٔ [`ravi-frgserver/`](ravi-frgserver/) قرار دارند. فایل `ravi-frgserver.rar` نسخهٔ اولیهٔ مخزن است و تغییرات داخل آن اعمال نشده‌اند.

برای اجرا و آزمون:

```sh
cd ravi-frgserver
npm ci
npm run dev
# در پایانه‌ای دیگر:
npm test
```

راهنمای کامل پروژه در [`ravi-frgserver/README.md`](ravi-frgserver/README.md)، راهنمای استقرار مرکز در [`ravi-frgserver/deploy/README.fa.md`](ravi-frgserver/deploy/README.fa.md)، آزمون بله در [`ravi-frgserver/BALE_MINIAPP.fa.md`](ravi-frgserver/BALE_MINIAPP.fa.md) و نتایج آزمون‌ها در [`ravi-frgserver/evaluation/CENTRAL_TEST_REPORT.fa.md`](ravi-frgserver/evaluation/CENTRAL_TEST_REPORT.fa.md) و [`ravi-frgserver/evaluation/LOAD_REPORT.fa.md`](ravi-frgserver/evaluation/LOAD_REPORT.fa.md) است. مرکز در پیش‌نمایش خاموش است و استقرار روی سرور واقعی هنوز انجام نشده است.
