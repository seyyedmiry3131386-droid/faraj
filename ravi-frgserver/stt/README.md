# مدل گفتار به متنِ خودمان (بدون API)

صدا روی سرور خود شما به متن تبدیل می‌شود، با مدل باز **Whisper** از طریق `faster-whisper`. هیچ کلیدی لازم نیست و صدا از سرور شما بیرون نمی‌رود.
پس از یک بار دانلود مدل، بدون اینترنت هم کار می‌کند.

## راه‌اندازی روی ویندوز

۱. Python 3.10 یا جدیدتر را از python.org نصب کنید و هنگام نصب «Add python.exe to PATH» را تیک بزنید.
۲. یک بار: `stt\setup-windows.bat` — مدل را دانلود می‌کند (medium حدود ۱٫۵ گیگابایت).
۳. هر بار: `stt\start-windows.bat` — پنجره را باز نگه دارید.
۴. در `.env` پروژه:

```
STT_URL=http://127.0.0.1:8765
STT_TOKEN=choose-a-long-random-ascii-token
```

و همان `STT_TOKEN` تصادفیِ ASCII بدون فاصله را پیش از اجرای سرور گفتار هم تنظیم کنید (`set STT_TOKEN=...`). بعد `npm run dev`.

روی لینوکس: `stt/setup.sh` و سپس `python stt/server.py`.

## کدام مدل؟

| مدل | پارامتر | حافظهٔ تقریبی (int8) | مناسب برای |
| --- | --- | --- | --- |
| `small` | ۲۴۴M | ~۱ GB | فقط آزمایش؛ برای فارسی ضعیف است |
| `medium` | ۷۶۹M | ~۲ GB | **پیش‌فرض** — سرور بدون کارت گرافیک |
| `large-v3-turbo` | ۸۰۹M | ~۲ GB | کیفیت نزدیک large با سرعت بیشتر؛ اگر CPU قوی یا GPU دارید |
| `large-v3` | ۱٫۵۵B | ~۴ GB | بهترین کیفیت؛ با GPU |

با `STT_MODEL=large-v3-turbo` عوض می‌شود. روی GPU انویدیا خودکار از CUDA استفاده می‌کند.

## سنجش دقت — پیش از اعتماد، اندازه بگیرید

```
pip install datasets soundfile
python stt/fetch_fleurs.py stt/samples --count 100   # ۱۰۰ جملهٔ فارسی با متن مرجع (FLEURS، گوگل)
python stt/evaluate.py stt/samples                    # WER و CER و سرعت
```

`evaluate.py` شکل‌های «ي/ی»، رقم فارسی/لاتین و نیم‌فاصله/فاصلهٔ معمولی را یکسان می‌کند. حذف کامل فاصله یا نوشتن عدد با حروف به‌جای رقم همچنان می‌تواند WER را افزایش دهد. خطاهای سرویس جدا شمرده می‌شوند؛ WER سرتاسری آن‌ها را متن خالی می‌گیرد و WER فقطِ درخواست‌های موفق هم جداگانه گزارش می‌شود.
FLEURS جملهٔ خوانده‌شده در محیط آرام است؛ کاربران شما از خیابان و با هیجان صحبت می‌کنند. **چند ده ضبط واقعی از جنس گزارش‌های خودتان** را هم با متن درستشان در همان پوشه بگذارید و بسنجید — آن عدد است که مهم است.

## کنترل بار و خطا

سرویس Python به‌صورت پیش‌فرض یک استنتاج هم‌زمان انجام می‌دهد و حداکثر دو درخواست شامل بارگذاری/انتظار/استنتاج را می‌پذیرد (`STT_MAX_PENDING=2`). درخواست اضافه با `503` و `Retry-After` برمی‌گردد؛ مرورگر صوت فعلی را برای تلاش مجدد نگه می‌دارد، نه اینکه آن را روی سرور ذخیره کند. تعداد اتصال‌های HTTP با `STT_MAX_CONNECTIONS=16`، مهلت سکون خواندن با `STT_READ_TIMEOUT=30` و مهلت کل بارگذاری با `STT_UPLOAD_TIMEOUT=120` ثانیه محدود است. این متغیرها را در **محیط سرویس Python** تنظیم کنید. کد خطای فایل خراب با صوت بدون گفتار متفاوت است.

مدت واقعی صوت نیز هنگام رمزگشایی محدود می‌شود، نه بر اساس metadata قابل‌اعتمادنبودنی فایل: پیش‌فرض `STT_MAX_SECONDS=185` ثانیه است (۵ ثانیه حاشیه برای ضبط سه‌دقیقه‌ای). صوت طولانی‌تر با `413/audio_too_long` رد می‌شود. در صورت تغییر این سقف، زمان پردازش و مهلت سرویس بالادستی را نیز بسنجید.

در فرایند Node نیز `STT_PROXY_MAX_ACTIVE=2` و در هر isolate سرویس Worker مقدار `STT_WORKER_MAX_ACTIVE=2` سقف مستقل می‌گذارند. این سقف‌ها سراسری یا مشترک بین چند فرایند/ماشین نیستند؛ برای چند سرور، ظرفیت، احراز هویت و محدودیت نرخ را در پروکسی مشترک هم تنظیم کنید. افزایش این عددها فقط با سنجش حافظه و سرعت واقعی سرور توصیه می‌شود.

```sh
npm run test:stt
# اگر سرویس توکن دارد، آن را از پیش به‌صورت امن در محیط بگذارید.
npm run eval:load -- --url http://127.0.0.1:8765 --scenario stt --audio /path/clip.wav --concurrency 8 --requests 8
# فقط نمونهٔ توسعهٔ ایزوله، نه سرور مرکزی فعال بدون امضای بله:
npm run eval:load -- --url http://127.0.0.1:4173 --scenario transcribe --audio /path/clip.wav --concurrency 8 --requests 8
```

اسکریپت فقط آمار و زمان را چاپ می‌کند، نه صوت یا متن؛ فشار روی سرور راه‌دور تنها با `--allow-remote` و اجازهٔ مالک انجام شود.

## آنچه آزموده شده و آنچه نه

- سرویس و خطاهای آن با مدل ساختگی آزمون رگرسیون دارند. علاوه بر آن، **Whisper medium پیش‌فرض و small واقعی** با محاسبهٔ int8 روی CPU، نمونه‌های محدود فارسی و زیر بار سنجیده شدند؛ نتیجه و محدودیت‌ها در [`evaluation/LOAD_REPORT.fa.md`](../evaluation/LOAD_REPORT.fa.md) است.
- این نمونه‌های کم و تک‌گوینده نمایندهٔ شرایط محیطی واقعی یا جمعیت کاربران سامانه نیستند؛ دقت را با صدای واقعی و متن مرجع روی سرور خودتان بسنجید. متن، نام‌ها و اعداد را همیشه با صوت بازبینی کنید.
